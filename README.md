
# 🌦️ Weather App

A responsive weather application built using HTML, CSS, and JavaScript that displays current weather information using the OpenWeatherMap API.

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Display temperature in Celsius
- 💧 Display humidity percentage
- 💨 Display wind speed
- 🌤️ Show weather condition icons
- ⚠️ Handle invalid city names
- 🔎 Search using the button or Enter key
- 🎨 Clean UI with a gradient background

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- OpenWeatherMap API
- Git and GitHub

## 📸 Preview

The application allows users to search for a city and view its temperature, humidity, wind speed, and current weather conditions.

## 🚀 How to Run

1. Clone this repository:

   `git clone https://github.com/PoojaShetty25/Weather-App-.git`

2. Open the project folder in Visual Studio Code.

3. Configure your OpenWeatherMap API key in the JavaScript code.

4. Open `index.html` in your browser or use Live Server.

5. Enter a city name and click the search button to view the weather.
